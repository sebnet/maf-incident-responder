# Spikes

Isolated, throwaway experiments to understand one MAF concept before integrating it into the responder.
Typically: copy a sample from `../agent-framework/dotnet/samples/`, switch it to NuGet packages, run it, break it.

- One folder per concept: `spikes/<phase>-<concept>/` (e.g. `spikes/3-magentic/`).
- Spikes are **not** part of `IncidentResponder.slnx` and are not built in CI.
- What you learn goes to `docs/notes/`, not here.
